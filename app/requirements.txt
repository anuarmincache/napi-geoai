# Dependências detectadas automaticamente pela Streamlit Community Cloud, por
# estarem no mesmo diretório do entrypoint (app/Home.py).
#
# O caminho é "." e não "..": o pip resolve caminho relativo de um arquivo de
# requirements a partir do diretório de trabalho, não do diretório do arquivo.
# A Cloud executa o pip na raiz do repositório, então "-e ..[ui]" apontava para
# fora do clone e a instalação falhava com «does not appear to be a Python
# project». Instalar o pacote é necessário: várias páginas importam geoai antes
# de qualquer outra coisa.
#
# Instalação local equivalente, a partir da raiz: pip install -e .[ui]
# Segredos: só no painel da Cloud, nunca neste arquivo.

-e .[ui]
